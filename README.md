# Japanese Adventure

MVP game học tiếng Nhật cho trẻ em Việt Nam tại Komorebi Village.

## Chạy local

```bash
npm install
npm run dev
```

Mở http://localhost:3000.

## Deploy Vercel

Import repository `khanhdinh112/Japanese-Adventure` trên Vercel, chọn framework **Next.js**, giữ lệnh build mặc định `npm run build`, sau đó Deploy.

MVP hiện có bản đồ 8 vùng, hồ sơ Hana, companion Momo, tiến trình học và nhiệm vụ đầu tiên. Supabase, xác thực phụ huynh và nội dung 80 stage sẽ được mở rộng ở các phase tiếp theo.
